=========================================
Emotion Recognition Dataset Folder
=========================================

This folder contains subfolders for different emotions.

FOLDER STRUCTURE:
-----------------
dataset/
  ├── happy/      (Place happy emotion audio files here)
  ├── sad/        (Place sad emotion audio files here)
  ├── angry/      (Place angry emotion audio files here)
  ├── neutral/    (Place neutral emotion audio files here)
  ├── fear/       (Place fear emotion audio files here)
  ├── surprise/   (Place surprise emotion audio files here)
  └── disgust/    (Place disgust emotion audio files here)

SUPPORTED AUDIO FORMATS:
------------------------
- .wav (recommended)
- .mp3
- .flac
- .m4a
- .ogg

INSTRUCTIONS:
-------------
1. Place your audio files in the corresponding emotion folder
2. Example: If you have a happy speech audio file, put it in dataset/happy/
3. The more files you have per emotion, the better the model will perform
4. Recommended: At least 10-20 audio files per emotion for good results

DATASET SOURCES:
----------------
You can download emotion datasets from:
- RAVDESS (Ryerson Audio-Visual Database of Emotional Speech and Song)
- TESS (Toronto Emotional Speech Set)
- EMO-DB (Berlin Database of Emotional Speech)

Once downloaded, organize the audio files by emotion into these folders.
